Editor's note

This started as a checklist in a text file and never really stopped being one. Every place on it came from somewhere specific: a bartender in Escondido who insisted on Vintana, a Fox 5 rundown of rooftops, a friend named Mark and his feelings about Cocina del Charro. Nothing here is sponsored, ranked, or reviewed. It's simply where we want to go next.

The list lives in a single Markdown file on GitHub. Tick a box there and this page updates itself. The map pins come from OpenStreetMap; where it couldn't find a place, we've dropped the pin on the neighborhood and said so.
